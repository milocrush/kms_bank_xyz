# KMS Bank XYZ

Prototipe Knowledge Management System untuk tesis Magister Sistem Informasi.

## Fitur

- Login dan autentikasi sederhana
- Dashboard pengetahuan
- Cari solusi berbasis keyword dan kategori
- Input pengetahuan
- Direktori ahli
- Validasi konten oleh Admin atau Knowledge Manager

## Pemetaan SECI

- Socialization: Direktori Ahli
- Externalization: Input Pengetahuan
- Combination: Dashboard Pengetahuan
- Internalization: Cari Solusi

## Cara Menjalankan

```bash
pip install -r requirements.txt
streamlit run app.py
```
